# Математика читательского ДНК: как считается совместимость

В этой статье подробно разберём, как устроен алгоритм **Книжного ДНК** изнутри: как нормализуются ответы, как определяется архетип из 16 возможных и как считается совместимость двух читателей в литературных дуэлях. Без магии и чёрных ящиков — только открытые формулы, веса и константы.

> Если вы ещё не расшифровали свой профиль вкуса, начните с вводного обзора [Какой я читатель: тест на читательский ДНК](/blog/kakoy-ya-chitatel) или сразу откройте [интерактивный тест](/reading-dna).

## 1. Шесть осей читательского вкуса

Каждая шкала в интерфейсе калибровки задаёт координату восприятия. Итоговый профиль читателя — это вектор из шести чисел в диапазоне **[0, 100]**:

- `storyFocus` — сюжет vs рефлексия (драйв и динамика против психологизма и философии)
- `emotionalWeight` — легко vs тяжело (лёгкое чтение для отдыха против высокой душевной нагрузки)
- `pace` — быстро vs погружение (темп чтения)
- `darkness` — светло vs мрачно (надежда и уют против саспенса, нуара и тьмы)
- `scope` — камерное vs эпическое (масштаб мира и событий)
- `complexity` — доступное vs многослойное (прозрачность языка против шифров и подтекстов)

Таким образом, читательский вкус кодируется точкой в 6-мерном пространстве восприятия и визуализируется на радаре читательского билета:

## 2. Как определяется архетип

Архетип — это эталонный профиль вкуса из 16 существующих. Каждый архетип описывается диапазонами допустимых значений по всем шести осям (`axisRanges`).

Алгоритм определения:

- Для каждого из 16 архетипов подсчитываются два показателя:
  - `hits` — количество осей, значение которых попало в диапазон архетипа;
  - `distance` — сумма нормализованных отклонений по осям, оставшимся вне диапазона: `Σ (Δ / 100)`.
- Выбирается архетип с максимальным значением `hits`.
- При равенстве попаданий побеждает архетип с минимальным `distance`.

```
hits = #{ key : axes[key] ∈ [range.min, range.max] }
distance = Σ (axes[key] < range.min ? (range.min - axes[key]) / 100
            : axes[key] > range.max ? (axes[key] - range.max) / 100 : 0)
```

Это модифицированная жадная классификация ближайшего соседа с приоритетом прямого попадания в коридор, а не евклидова расстояния.

## 3. Совместимость двух читателей (0–97%)

Совместимость в литературной дуэли — это число от **0 до 97%**. Максимум ограничен 97%, потому что абсолютно идентичного восприятия литературы между двумя живыми людьми не существует: каждый читает текст через собственный жизненный опыт.

Расчёт проходит в несколько этапов.

### 3.1 Подобие осей восприятия

Для каждой оси вычисляется нелинейное подобие:

```
sim_axis = 1 - (|a - b| / 100) ^ 1.3
```

Показатель степени `1.3` выбран не случайно: малые расхождения (в пределах 10–15 пунктов) практически не снижают балл, тогда как полярные различия (например, 10 против 90) штрафуются с прогрессирующей строгостью.

Затем значения агрегируются с учётом весов осей:

```
w = {
  storyFocus: 0.20,
  emotionalWeight: 0.20,
  pace: 0.15,
  darkness: 0.15,
  scope: 0.15,
  complexity: 0.15
}
axesSim = Σ w[key] * sim_axis[key]
```

### 3.2 Доля общих книг («скачок Эврики»)

Сравниваются списки любимых книг оппонентов (по совпадению ID в каталоге или нормализованному названию). Количество совпадений ограничивается тремя:

```
shared = min(3, count of common favorite books)
bookScore = (shared / 3) ^ 0.3
```

Степень `0.3` создаёт «эффект Эврики»: даже одна общая любимая книга — это сильнейший культурный маркер, который сразу даёт резкий скачок сходства вкусов (~69% от максимума за книги).

### 3.3 Жанры и авторы (коэффициент Жаккара)

Для пересечения жанров и любимых авторов используется классический коэффициент Жаккара:

```
J(A, B) = |A ∩ B| / |A ∪ B|
```

Вычисляются:
- `likedJaccard` — совпадение по любимым жанрам;
- `dislikedJaccard` — совпадение по нелюбимым жанрам;
- `authorsJaccard` — совпадение по авторам.

Жанровый балл в отчёте:

```
genreScore = (likedJaccard * 0.0556 + dislikedJaccard * 0.1667) / (0.0556 + 0.1667) * 100
```

> **Психологический нюанс:** Нелюбимые жанры весят в 3 раза больше любимых (`0.1667` против `0.0556`). В социальной психологии давно известен факт: общая неприязнь и отвержение одних и тех же штампов объединяют людей сильнее, чем спокойная симпатия к популярным жанрам.

### 3.4 Взвешивание по доступным данным

Базовые веса компонентов:

```
axes: 0.5556
books: 0.1111
dislikedGenres: 0.1667
authors: 0.1111
likedGenres: 0.0556
```

Если у одного из пользователей нет определённых данных (например, не указаны авторы), алгоритм не занижает оценку, а перераспределяет вес:

```
t = (Σ w_i * score_i) / (Σ w_i)   // только по заполненным полям
```

### 3.5 Коррекции: конфликты и бонусы

Перед финальным расчётом к значению `t` применяются три поправки:

- **Жанровый конфликт:** если любимый жанр одного читателя входит в список нелюбимых у другого — накладывается штраф: `t -= 0.08 * max(conflictAB, conflictBA)`.
- **Общий криптонит (эффект Боссона):** если нелюбимые книги читателей совпадают — начисляется бонус солидарности: `t += 0.04`.
- **Святыня vs криптонит (ценностный конфликт):** если любимая книга одного человека оказывается криптонитом другого — применяется жёсткий штраф: `t -= 0.25`.

### 3.6 Калибровка через сигмоиду

Итоговая взвешенная сумма сначала удерживается в диапазоне `[0, 1]`, а затем преобразуется логистической сигмоидой:

```
t_clamped = clamp(t, 0, 1)
calibration: k = 6, t0 = 0.39, max = 97
compatibility = max / (1 + exp(-k * (t_clamped - t0)))
compatibility = round(clamp(compatibility, 0, 97))
```

Сигмоида растягивает средний диапазон значений, делая распределение совместимости психологически комфортным и контрастным.

## 4. Вердикты дуэли

В зависимости от итогового процента и наличия критических конфликтов система выносит вердикт:

- **≥ 90%** — «Литературные соулмейты (Абсолютный книжный резонанс)»
- **≥ 75%** — «Книжные единомышленники (Отличное взаимопонимание вкусов)»
- **≥ 50%** — «Гармония контрастов (Общие темы с яркими спорами)»
- **≥ 30%** — «Разные литературные миры (Редкие точки соприкосновения)»
- **< 30%** — «Полярные противоположности (Литературная дуэль на смерть)»
- **При конфликте святыни и криптонита** — «Взрывоопасная смесь: ваша любимая книга — криптонит оппонента!»

## 5. Итог

Модель Книжного ДНК — это открытая инженерная эвристика, в которой:
- отсутствуют штрафы за пустые поля;
- нелинейная функция защищает от случайных искажений;
- учитываются не только явные симпатии, но и культурные антипатии;
- распределение откалибровано в наглядный диапазон 0–97%.
